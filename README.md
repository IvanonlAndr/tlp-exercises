# tlp-exercises

Exercises from *Think Like a Programmer* by V. Anton Spraul, done in Python as practice.

## About

This is just practice — don't expect it to be professional, clean, or fast. The
goal here is working through logic, problem-solving, and fundamentals, not
producing polished code. Some exercises may be incomplete, half-finished, or
revisited later as understanding improves.

## Structure

Each exercise gets its own folder, named after the problem it covers.

| Folder | Exercise | Status |
|---|---|---|
| [`thefgc`](./thefgc) | Fox, Goose, and Corn river-crossing puzzle | Manual move simulation working; automated solver not yet implemented |

## Notes

- Code here reflects where I was at while learning — later exercises should get
  cleaner and more capable as I go.
